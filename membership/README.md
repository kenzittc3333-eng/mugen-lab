# MUGEN学習LAB 会員機能（準備中）
本番の公開サイトへの変更はありません。Supabase接続後に検証するためのデータベース案です。まだログイン画面・管理画面・教材表示は実装されていません。

## 決定済みの仕様
- 教科ごとに無料教材と有料教材を混在表示。
- メールアドレス・パスワードによる登録、メール確認、ログイン、再設定。
- 管理者が入金を手動確認し、教材単位で1〜366日の利用を付与。
- 教材タイトル・教科・公開状態・料金・標準利用日数を管理。
- 有料HTMLは公開GitHubに保存せず、RLSで保護する別テーブルに置く。
- サーバー時刻で期限と取消を確認。会員が自分で期間を延長できない。
- 最初の管理者は接続済みプロジェクトの確認後、認証済みの本人UIDを確認して管理用SQLで登録する。先着登録者を管理者にはしない。

## 接続後の作業
1. 利用者所有のSupabaseプロジェクトを選択。既存テーブルとの衝突を確認。
2. 独立した検証環境でschema.sqlを適用。
3. メール認証、配信元SMTP、公開URLと再設定戻り先を設定。
4. 本番商用利用に適したホストで会員画面を構築。GitHub Pagesは無料教材の入り口にする。
5. 管理者画面、入金確認、期間延長・取消、教材登録を実装。
6. 無料LABに有料教材を案内するリンクを追加。
7. 未ログイン、未購入、別会員、開始前、期限切れ、取消済みで本文が取得できないことを実際のDBで検証。
8. 一般会員から教材変更・権限付与・管理者化できないこと、本人によるパスワード再設定を検証。

## 表示時の保護
HTML教材は会員画面と同一オリジンで直接実行しない。sandbox付きiframe等でトークン・管理者画面から分離する。
本文取得ごとにRLSを通す。公開ストレージや公開リポジトリに本文を置かない。
期限後は新規取得を拒否できるが、既にダウンロード・撮影された内容は回収できない。
料金変更は既存の利用期限を自動変更しない。既存の無料教材は指定があるまで無料公開を維持。
